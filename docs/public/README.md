# 小鱼精灵公开文档

小鱼精灵当前以 Android + Lua 为第一版目标。这里收录已经实现、脚本用户可以直接依赖的
API 说明；未完成能力不会提前写入。

## 阅读入口

- [交互式脚本文档](脚本文档.html)：目录、搜索、参数摘要和函数正文集中在一个页面中。
- [Markdown 脚本文档](脚本文档.md)：适合在 Git 仓库中阅读和链接。

建议先阅读“概述”中的 API 总览、命名空间和类型约定，再进入对应功能分类查找函数。

## 发布说明

本目录是文档发布白名单。部署时以 `docs/public/` 为站点根目录，并保留以下相对结构：

```text
脚本文档.html
脚本文档/
  catalog.json
  md/
```

网页只有一个 HTML 入口，但它会按需读取目录 JSON 和 Markdown 正文，因此发布时不能只复制
HTML 文件。内部架构、源码说明、计划和历史记录不属于公开站点。

## 反馈问题

反馈脚本 API 问题时，请同时提供：

- 使用的函数名和最小复现脚本。
- 实际参数、返回值或完整错误信息。
- Android 版本、是否启用 Root，以及普通脚本或 `.alpkg` 运行方式。
- 预期结果和实际结果。
