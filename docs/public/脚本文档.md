# 小鱼精灵脚本文档

这是公开发布和 Git 仓库中稳定可阅读的脚本文档入口。文档按功能主题维护，稳定核心 API 保持
独立函数页；需要目录搜索和参数摘要时，可打开 [交互式脚本文档](脚本文档.html)。

脚本默认启用小鱼精灵 `m` API，因此示例优先使用 `appIsFront()`、`capture(path)`、
`thread.newThread()` 这类实际调用写法。交互式文档右侧标题保留 `m.xxx`，用于标识公开命名
空间归属；显式写成 `m.xxx()` 也始终有效。
