params: "x1, y1, x2, y2: integer, dp: number, minDist: number, param1: number, param2: number, minRadius: number, maxRadius: number"
returns: "table"
---

**方法名称：** 在当前截图区域中查找圆形。

**语法：** `findCircle(x1, y1, x2, y2, dp, minDist, param1, param2, minRadius, maxRadius)`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `x1, y1, x2, y2` | `integer` | 是 | 分析区域。 |
| `dp` | `number` | 是 | 累加器分辨率与原图分辨率的反比。 |
| `minDist` | `number` | 是 | 圆心之间的最小距离。 |
| `param1` | `number` | 是 | 边缘检测高阈值。 |
| `param2` | `number` | 是 | 圆心累加器阈值；越小通常会检测到更多圆。 |
| `minRadius` | `number` | 是 | 最小半径。 |
| `maxRadius` | `number` | 是 | 最大半径。 |

| 返回值 | 说明 |
|---|---|
| `table` | 返回 `{ {x=圆心横坐标, y=圆心纵坐标, r=半径}, ... }`；未检测到圆时为空 table。 |

**详细说明：**

该接口使用 OpenCV 的霍夫圆检测。启用虚拟坐标时，区域、距离、半径和返回值都会按基准尺寸换算。
参数不合法或图像处理失败时会抛出 Lua 错误。

```lua
local circles = findCircle(0, 0, 0, 0, 1, 20, 100, 30, 5, 100)
for _, circle in ipairs(circles) do
    print(circle.x, circle.y, circle.r)
end
```
