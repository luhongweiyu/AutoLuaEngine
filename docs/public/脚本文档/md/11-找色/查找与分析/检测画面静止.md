**方法名称：** 判断一个区域在指定时间后是否保持不变。

**语法：** `isDisplayDead(x1, y1, x2, y2, seconds)`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `x1, y1, x2, y2` | `integer` | 是 | 要比较的区域。 |
| `seconds` | `number` | 是 | 两次读取之间等待的秒数；小于 `0` 时按 `0` 处理。 |

| 返回值 | 说明 |
|---|---|
| `true` | 两次读取的区域 RGB 内容相同。 |
| `false` | 内容不同，或当前截图不可用。 |

**详细说明：**

函数会读取一次区域、等待指定时间、再读取一次并比较。它遵守当前截图缓存、固定图片屏幕和锁帧
状态：若正在使用固定图片或已调用 `keepCapture()`，两次读取会是同一帧，因此通常返回 `true`。

```lua
if isDisplayDead(0, 0, 300, 300, 2) then
    print("区域两秒内没有变化")
end
```
