---
params: "x1, y1, x2, y2: integer, firstColor: string, offsetColor: string, direction: integer?, similarity: number?"
returns: "table 或 nil"
---

**方法名称：** 查找区域内全部符合多点颜色规则的位置。

**语法：** `findMultiColorAll(x1, y1, x2, y2, firstColor, offsetColor[, direction[, similarity]])`
或 `findMultiColorAllT(arguments)`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `x1, y1, x2, y2` | `integer` | 是 | 查找区域。 |
| `firstColor` | `string` | 是 | 基准点颜色规则。 |
| `offsetColor` | `string` | 是 | 相对基准点的偏移颜色规则。 |
| `direction` | `integer?` | 否 | 兼容方向 `0..4`，默认 `0`。 |
| `similarity` | `number?` | 否 | 相似度，范围 `0..1`，默认 `1`。 |
| `arguments` | `table` | 仅 `findMultiColorAllT` | 位置参数 table，等价于 `findMultiColorAll(table.unpack(arguments))`。 |

| 返回值 | 说明 |
|---|---|
| `table` | 正常读取截图时返回 `{ {x=..., y=...}, ... }`；没有命中时为空 table。 |
| `nil` | 当前截图不可用。 |

**详细说明：**

该函数不跳过相邻命中，会按扫描方向返回全部符合规则的基准点。启用虚拟坐标时，输出坐标会换算到
当前基准尺寸。

```lua
local points = findMultiColorAll(0, 0, 0, 0, "FF0000", "10|0|00FF00", 0, 0.95)
for _, point in ipairs(points or {}) do
    print(point.x, point.y)
end
```
