---
params: "x1, y1, x2, y2: integer, firstColor: string, offsetColor: string, direction: integer?, similarity: number?"
returns: "integer, integer"
---

**方法名称：** 查找第一个符合首色和偏移色规则的位置。

**语法：** `findMultiColor(x1, y1, x2, y2, firstColor, offsetColor[, direction[, similarity]])`
或 `findMultiColorT(arguments)`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `x1, y1, x2, y2` | `integer` | 是 | 查找区域。 |
| `firstColor` | `string` | 是 | 基准点颜色，可使用候选颜色和容差。 |
| `offsetColor` | `string` | 是 | 相对基准点的规则，例如 `"10|0|00FF00,0|10|0000FF"`。 |
| `direction` | `integer?` | 否 | 兼容方向 `0..4`，默认 `0`。 |
| `similarity` | `number?` | 否 | 相似度，范围 `0..1`，默认 `1`。 |
| `arguments` | `table` | 仅 `findMultiColorT` | 位置参数 table，等价于 `findMultiColor(table.unpack(arguments))`。 |

| 返回值 | 说明 |
|---|---|
| `integer, integer` | 找到时返回基准点 `x, y`。 |
| `-1, -1` | 未找到或截图不可用。 |

**详细说明：**

偏移颜色中的 `dx, dy` 相对于命中的基准点。启用虚拟坐标时，区域、偏移和返回坐标都会按当前
基准尺寸换算；格式或相似度不合法时会抛出 Lua 参数错误。

```lua
local x, y = findMultiColor(
    0, 0, 0, 0,
    "FF0000",
    "10|0|00FF00,0|10|0000FF",
    0,
    0.95
)
print(x, y)
```
