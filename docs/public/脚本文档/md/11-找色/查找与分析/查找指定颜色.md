---
params: "x1, y1, x2, y2: integer, color: string, direction: integer?, similarity: number?"
returns: "string, integer, integer 或 nil, -1, -1"
---

**方法名称：** 在区域内查找第一个匹配的颜色。

**语法：** `findColor(x1, y1, x2, y2, color[, direction[, similarity]])` 或
`findColorT(arguments)`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `x1, y1, x2, y2` | `integer` | 是 | 查找区域；两个角的顺序不限。 |
| `color` | `string` | 是 | 颜色规则，可用 `|` 写多个候选颜色。 |
| `direction` | `integer?` | 否 | `0` 左上、`1` 中心向外、`2` 右下、`3` 左下、`4` 右上；默认 `0`。 |
| `similarity` | `number?` | 否 | 相似度，范围 `0..1`，默认 `1`。 |
| `arguments` | `table` | 仅 `findColorT` | 位置参数 table，等价于 `findColor(table.unpack(arguments))`。 |

| 返回值 | 说明 |
|---|---|
| `string, integer, integer` | 找到时返回命中的颜色文本和坐标 `x, y`。 |
| `nil, -1, -1` | 未找到或截图不可用。 |

**详细说明：**

多个候选颜色时按颜色规则顺序选择首个匹配色。兼容方向使用 `0..4`，启用虚拟坐标后输入和输出
坐标都按基准尺寸换算。

```lua
local matched, x, y = findColor(0, 0, 0, 0, "FF0000|00FF00", 1, 0.95)
if matched then
    print(matched, x, y)
end
```
