returns: "integer, integer 或 nil, string"

**方法名称：** 在当前截图缓存中执行原生多点找色。

**语法：** `findColors(x1, y1, x2, y2, dir, sim, colors)`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `x1, y1, x2, y2` | `integer` | 是 | 查找范围。 |
| `dir` | `integer` | 是 | 扫描方向，取值 `1..8`。 |
| `sim` | `integer` | 是 | 默认 RGB 容差，写作 `0xRRGGBB`。 |
| `colors` | `string` | 是 | 多点规则：`x|y|RRGGBB`，用英文逗号分隔；单点可追加 `-RRGGBB` 覆盖默认容差。 |

| 返回值 | 说明 |
|---|---|
| `integer, integer` | 找到时返回命中基准点的 `x, y`。 |
| `nil, string` | 未找到或处理失败时返回原因。 |

**详细说明：**

这是小鱼原生 `m.findColors` 接口，直接使用当前截图缓存，不需要额外的“是否截屏”参数。它的方向
约定为 `1..8`，并且不参与 `setScreenScale` 的虚拟坐标换算；与本分类的兼容找色接口不能混用方向。

```lua
local x, y = findColors(
    0, 0, 1079, 1919,
    2,
    0x101010,
    "0|0|FFFFFF,10|5|FF0000-101010"
)

if x then
    print("找到", x, y)
end
```
