**方法名称：** 扩展取色、多点找色、点阵识字和多模板找图。

**语法：** `getPixelColor(...)`、`findMultiColor(...)`、`findPicEx(...)` 等。

**参数说明：**

| 方法 | 参数摘要 | 返回值 |
|---|---|---|
| `getPixelColor(x, y[, kind])` | 坐标；`kind=1` 返回整数 | `RRGGBB string` 或 `integer` |
| `getScreenPixel(x1, y1, x2, y2)` | 区域 | `width, height, pixels` |
| `colorToRGB(color)` / `colorDiff(a, b)` | 整数或 `RRGGBB` | `r,g,b` / 差值 |
| `cmpColor(x, y, color[, similarity])` | 坐标、颜色、相似度 | `1` 或 `0` |
| `getColorNum(x1, y1, x2, y2, color[, similarity])` | 区域、颜色、相似度 | 命中数量 |
| `cmpColorEx(description[, similarity])` | `x|y|颜色,...` | `1` 或 `0` |
| `findColor(x1, y1, x2, y2, colors[, direction, similarity])` | 区域和颜色集合 | `matchedColor,x,y` 或 `nil,-1,-1` |
| `findMultiColor(...)` | 区域、首色、偏移色、方向、相似度 | `x,y` 或 `-1,-1` |
| `findMultiColorAll(...)` | 同上 | `{ {x,y}, ... }` |
| `isDisplayDead(x1, y1, x2, y2, seconds)` | 区域和等待秒数 | `boolean` |
| `findCircle(x1, y1, x2, y2, dp, minDist, param1, param2, minRadius, maxRadius)` | OpenCV 霍夫圆参数 | `{ {x,y,r}, ... }` |
| `setDict(index, dictionary)` / `useDict(index)` | 字库编号和内容 | `1` 或 `0`，可带错误 |
| `ocr(...)` / `ocrj(...)` | 区域、颜色、相似度 | 文本 / JSON 字符串 |
| `findStr(...)` / `findStrEx(...)` | 区域、候选文字、颜色、相似度 | 首个结果 / JSON 字符串 |
| `findPicEx(...)` / `findImage(...)` | 区域、多模板名、相似度 | `name,x,y` 或 `nil,-1,-1` |
| `findPicAllPoint(...)` | 区域、单模板、相似度 | 坐标 table |
| `findPicFast(...)` | 区域、多模板、偏色、方向、相似度 | `index, points` |
| `PaddleOcr.loadModel/loadOnnxModel/detect*` | Java Bitmap 与 ONNX 模型 | `boolean` / JSON 字符串 |

`cmpColorExT(table)`、`findColorT(table)`、`findMultiColorT(table)`、
`findMultiColorAllT(table)` 是对应位置参数函数的 table 入口。`ocrNew`、`ocrjNew`、
`findStrExNew` 会先按首个 `index` 参数切换字库。

| 返回值 | 说明 |
|---|---|
| `integer`、`string` 或多个标量 | 单点、计数、颜色和首个命中接口按上表返回。 |
| `table` | 全部命中、像素点阵和找圆接口返回 Lua table。 |
| `nil, string` | 截图、模板或字库处理失败时，支持错误返回的接口会附带原因。 |

**详细说明：**

颜色写法支持 `RRGGBB`，也支持 `RRGGBB-DRDGDB` 容差；多个候选颜色用 `|` 分隔。多点
偏移写法为 `dx|dy|颜色,...`。扩展方向为 `0` 左上、`1` 中心向外、`2` 右下、
`3` 左下、`4` 右上。

`findPicFast` 按 `|` 分隔的模板顺序查找，返回第一个有命中的模板索引（从 `0`
开始）以及该模板的全部非重叠坐标；全部未命中时返回 `-1, {}`。方向为 `1` 时，
坐标按离查找区域中心由近到远排列。

`lr.findPic` 使用多模板返回 `name, x, y`；默认 `m.findPic` 仍使用图像章节中的单模板
接口和 `1..8` 扫描方向，不会被兼容层改变。

Java 兼容 `PaddleOcr` 使用当前真实 PP-OCRv4 ONNX 推理核心。NCNN 模型没有运行后端，
`loadModel(false)` 和 `loadNnccModel(...)` 返回 `false`；详细字段见 Java 分类中的
“PaddleOCR 兼容”。

```lua
local x, y = findMultiColor(
    0, 0, 0, 0,
    "FF0000",
    "10|0|00FF00,0|10|0000FF",
    0,
    0.9
)
print(x, y)

local circles = findCircle(0, 0, 0, 0, 1, 20, 100, 30, 5, 100)
print(#circles)
```
