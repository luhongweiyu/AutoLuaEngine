# 找色概述

找色功能直接读取当前截图来源，不会为了单次调用额外保存图片。需要在一连串操作中固定同一帧时，
先调用 `keepCapture()`，完成后调用 `releaseCapture()`。

| 子分类 | 内容 | 入口 |
|---|---|---|
| 取色与转换 | 单点颜色、区域像素、RGB 通道和颜色差值 | [获取单点颜色](取色与转换/获取单点颜色.md) |
| 比色与统计 | 单点、多点比色和区域颜色数量 | [单点比色](比色与统计/单点比色.md) |
| 查找与分析 | 原生多点找色、兼容找色、静屏检测和找圆 | [原生多点找色](查找与分析/原生多点找色.md) |

`findColors` 是小鱼原生多点找色接口，方向为 `1..8`，不参与虚拟坐标缩放。其余本分类的兼容
取色接口在启用 `setScreenScale(true, width, height)` 后使用虚拟坐标；带方向的兼容接口使用
`0..4`：左上、中心向外、右下、左下、右上。

颜色通常写成 `RRGGBB`，也可写为 `RRGGBB-DRDGDB` 指定 RGB 三通道容差。需要多个可选颜色时
用 `|` 分隔；多点描述使用英文逗号分隔多个 `x|y|颜色` 项。
