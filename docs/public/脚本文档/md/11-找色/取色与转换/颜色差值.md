**方法名称：** 计算两个 RGB 颜色的通道绝对差值之和。

**语法：** `colorDiff(first, second)`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `first` | `integer 或 string` | 是 | 第一种颜色，格式同 `colorToRGB`。 |
| `second` | `integer 或 string` | 是 | 第二种颜色，格式同 `colorToRGB`。 |

| 返回值 | 说明 |
|---|---|
| `integer` | `abs(r1-r2) + abs(g1-g2) + abs(b1-b2)`，范围 `0..765`。 |

**详细说明：**

返回值越小表示两种颜色越接近；该函数不读取截图。颜色格式不合法时会抛出 Lua 参数错误。

```lua
local diff = colorDiff("FF0000", "F00010")
print(diff)
```
