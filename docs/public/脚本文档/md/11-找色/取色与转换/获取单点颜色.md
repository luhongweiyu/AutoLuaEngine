**方法名称：** 获取当前截图中的一个像素颜色。

**语法：** `getPixelColor(x, y[, kind])`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `x` | `integer` | 是 | 像素横坐标。 |
| `y` | `integer` | 是 | 像素纵坐标。 |
| `kind` | `integer?` | 否 | 传 `1` 返回整数颜色；省略或其他值返回六位字符串。 |

| 返回值 | 说明 |
|---|---|
| `string` | 默认返回大写 `RRGGBB`，例如 `"F8F999"`。 |
| `integer` | `kind = 1` 时返回 `0xRRGGBB` 整数。 |
| `nil, string` | 截图不可用或坐标超出当前屏幕时返回原因。 |

**详细说明：**

该函数读取当前截图来源；固定图片屏幕、截图缓存和锁帧规则与图像分类一致。启用虚拟坐标后，
传入的坐标会按当前基准尺寸换算到真实截图。

```lua
local color, errorMessage = getPixelColor(120, 240)
assert(color, errorMessage)
print(color) -- 例如 F8F999

local value = assert(getPixelColor(120, 240, 1))
print(string.format("%06X", value))
```
