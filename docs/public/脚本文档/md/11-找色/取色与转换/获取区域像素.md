---

**方法名称：** 获取一个区域的 RGB 像素整数数组。

**语法：** `getScreenPixel(x1, y1, x2, y2)`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `x1, y1, x2, y2` | `integer` | 是 | 区域两个角的坐标；四个值都为 `0` 时读取完整屏幕。 |

| 返回值 | 说明 |
|---|---|
| `integer, integer, table` | 成功时依次返回宽、高和按从左到右、从上到下排列的 `0xRRGGBB` 整数 table。 |
| `-1, -1, nil` | 当前截图不可用或区域无有效像素。 |

**详细说明：**

区域边界会限制在当前截图内，返回宽高使用包含两端的像素数量。启用虚拟坐标后，区域坐标先换算到
真实截图；返回的像素数值不带 alpha 通道。

```lua
local width, height, pixels = getScreenPixel(0, 0, 9, 9)
assert(pixels)
print(width, height, string.format("%06X", pixels[1]))
```
