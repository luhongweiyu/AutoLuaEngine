**方法名称：** 拆分 RGB 颜色通道。

**语法：** `colorToRGB(color)`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `color` | `integer 或 string` | 是 | `0xRRGGBB` 整数，或 `RRGGBB`、`#RRGGBB`、`0xRRGGBB` 字符串。 |

| 返回值 | 说明 |
|---|---|
| `integer, integer, integer` | 依次返回 `red`、`green`、`blue`，每项范围为 `0..255`。 |

**详细说明：**

该函数只转换颜色值，不读取截图。颜色格式不合法时会抛出 Lua 参数错误。

```lua
local r, g, b = colorToRGB("#F8F999")
print(r, g, b) -- 248 249 153
```
