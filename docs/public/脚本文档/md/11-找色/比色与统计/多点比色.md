**方法名称：** 判断多个绝对坐标是否同时匹配颜色。

**语法：** `cmpColorEx(description[, similarity])` 或 `cmpColorExT(arguments)`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `description` | `string` | 是 | 多点描述：`x|y|颜色,x|y|颜色`。每项颜色可使用容差或候选颜色。 |
| `similarity` | `number?` | 否 | 相似度，范围 `0..1`，默认 `1`。 |
| `arguments` | `table` | 仅 `cmpColorExT` | 位置参数 table，等价于 `cmpColorEx(table.unpack(arguments))`。 |

| 返回值 | 说明 |
|---|---|
| `1` | 全部点都匹配。 |
| `0` | 任一点不匹配或当前截图不可用。 |

**详细说明：**

多点描述使用绝对坐标，不是相对首点的偏移。启用虚拟坐标时，描述中的每个坐标都会按当前基准尺寸
换算；描述格式或颜色格式错误时会抛出 Lua 参数错误。

```lua
local ok = cmpColorEx("100|200|FFFFFF,120|200|FF0000-101010", 0.98)
print(ok == 1)
```
