**方法名称：** 统计区域内匹配颜色的像素数量。

**语法：** `getColorNum(x1, y1, x2, y2, color[, similarity])`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `x1, y1, x2, y2` | `integer` | 是 | 区域两个角的坐标。 |
| `color` | `string` | 是 | 颜色规则，格式同 `cmpColor`。 |
| `similarity` | `number?` | 否 | 相似度，范围 `0..1`，默认 `1`。 |

| 返回值 | 说明 |
|---|---|
| `integer` | 匹配像素数；当前截图不可用时返回 `0`。 |

**详细说明：**

区域会被限制在当前截图范围内，两个角的传入顺序不影响统计范围。该函数会扫描区域中的每一个像素，
大范围调用应避免放在高频循环中。

```lua
local count = getColorNum(0, 0, 200, 200, "FF0000", 0.95)
print("红色像素数", count)
```
