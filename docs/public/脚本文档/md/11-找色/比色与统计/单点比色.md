**方法名称：** 判断一个像素是否匹配指定颜色。

**语法：** `cmpColor(x, y, color[, similarity])`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `x` | `integer` | 是 | 像素横坐标。 |
| `y` | `integer` | 是 | 像素纵坐标。 |
| `color` | `string` | 是 | `RRGGBB`、带容差的 `RRGGBB-DRDGDB`，或以 `|` 分隔的候选颜色。 |
| `similarity` | `number?` | 否 | 相似度，范围 `0..1`，默认 `1`。 |

| 返回值 | 说明 |
|---|---|
| `1` | 当前像素匹配任一候选颜色。 |
| `0` | 不匹配或当前截图不可用。 |

**详细说明：**

相似度会转换为 RGB 通道容差；颜色文本中显式给出的 `DRDGDB` 容差与相似度容差取每个通道的较大值。
启用虚拟坐标后，坐标会先换算到真实截图。

```lua
if cmpColor(120, 240, "F8F999-101010", 0.98) == 1 then
    print("颜色匹配")
end
```
