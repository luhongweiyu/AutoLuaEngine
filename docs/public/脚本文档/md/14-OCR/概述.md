`m.ocr` 使用 RapidOCR 兼容的 PP-OCR ONNX 检测、识别和可选方向分类模型。基础 APK 不携带
ONNX Runtime 核心库或 PP-OCRv4 mobile 模型。首次使用预设模型前，将目标 CPU ABI 对应的
`libonnxruntime.so` 和下列四个文件平铺放入 `/sdcard/xiaoyv/extensions/`，再在 App 的“扩展”页
逐个点击“导入”：

- `ch_PP-OCRv4_det_mobile.onnx`
- `ch_PP-OCRv4_rec_mobile.onnx`
- `ch_ppocr_mobile_v2.0_cls_mobile.onnx`
- `ppocr_keys_v1.txt`

“导入”只复制文件，不会执行 native 代码；`loadBuiltin()` 第一次实际创建模型时才加载运行时和文件。
文件名、CPU ABI、依赖和内容由脚本作者自行负责，加载失败会返回底层错误。需要其他语言或自训练模型时
继续使用 `load(...)` 指定文件；模型不再使用时调用 `release(name)`。

预设模型流程：

```lua
capture("/sdcard/xiaoyv/scripts/current.png")
m.ocr.loadBuiltin() -- 默认模型名称为 builtin
local result = m.ocr.read("builtin", "/sdcard/xiaoyv/scripts/current.png")
m.ocr.release("builtin")
```

自定义模型文件必须是 Android 可直接读取的普通文件路径，并同样先导入目标 ABI 对应的
`libonnxruntime.so`。建议与脚本放在共享存储目录，例如：

```text
/sdcard/xiaoyv/models/dbnet.onnx
/sdcard/xiaoyv/models/crnn.onnx
/sdcard/xiaoyv/models/angle.onnx
/sdcard/xiaoyv/models/keys.txt
```

自定义模型流程：

```lua
capture("/sdcard/xiaoyv/scripts/current.png")
m.ocr.load("main", detPath, recPath, clsPath, keysPath)
local result = m.ocr.read("main", "/sdcard/xiaoyv/scripts/current.png")
m.ocr.release("main")
```

同一模型名称、相同配置的重复 `load` 会直接复用已加载 session，不增加引用次数。不同名称使用
相同配置时也会共享底层 session，所有名称都 `release` 后才真正释放 ONNX 模型内存。
