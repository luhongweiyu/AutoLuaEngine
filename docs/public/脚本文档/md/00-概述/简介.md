当前版本面向 Android + Lua，提供自动化 API、脚本子线程和动态 Java 互操作。默认使用
小鱼精灵 `m` API；需要兼容已有脚本时，也可以切换到文档列出的兼容命名空间。

本文档以已经实现、脚本可以依赖的调用方式为主，也收录 C ABI、扩展开发资料以及明确标注
状态的未完成或实验能力。请从左侧分类进入函数页查看可用状态、参数、返回值、失败情况和示例；
尚未闭环的能力不能按已可运行接口使用。

## Android 客户端

客户端底部包含“脚本、市场、扩展、状态、设置”五个页面。脚本页与悬浮控制使用同一个运行
入口，当前支持直接运行 `.lua` 和 `.alpkg`；选择其他格式时会明确提示不支持。

首次使用悬浮控制时，客户端会引导开启“显示在其他应用上层”权限。扩展文件或文件夹放入
`/sdcard/xiaoyv/extensions` 后，可在扩展页点击“导入”；脚本真正使用扩展时才会加载。

Root 模式和非 Root 模式使用同一套脚本 API。每次脚本运行使用独立 Worker，脚本结束后进程
退出；Root 模式下 Worker 以 root 身份运行，非 Root 模式下则使用应用自身权限。
