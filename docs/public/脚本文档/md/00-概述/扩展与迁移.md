# 扩展开发与旧脚本迁移

小鱼精灵默认使用 `m` 命名空间，并把它的一级成员导出为同名全局函数。新脚本应按本目录中
`m` 的正式签名编写；完整写法（例如 `m.ime.lock()`）与默认全局写法（例如 `ime.lock()`）
等价。

| 使用场景 | 当前入口 | 文档位置 |
|---|---|---|
| 网络与通信 | `httpGet`、`httpPost`、文件传输、WebSocket、`require("socket")`、`require("socket.http")` | 网络与通信 |
| 加密 | `cryptLib.*` | 安全与数据 |
| 触控 | `setScreenScale`、`tap`、`swipe` | 输入 |
| 输入法 | `m.ime.*` | 输入法 |
| 图像 | 截图缓存、`findPic`、`findPicEx`、`findPicFast`、`cv.*`、`import("org.opencv.*")` | 图像 |
| 找色 | `getPixelColor`、`cmpColor`、`findColors`、`findColor`、`findMultiColor`、`findCircle` 等 | 找色 |
| 设备与文件 | `zip`、`playAudio`、`setTimer` 等 | 设备 |
| 无障碍 | 选择器、节点对象、`nodeLib.*` | 无障碍 |
| Lua 运行时 | `io.*`、`os.*`、实验性 `ffi.*` | 运行时扩展 |
| 扩展开发 | C ABI、插件函数表、ImGui C ABI | 扩展开发 |

## 旧脚本迁移

迁移懒人精灵或触动精灵脚本时，可在脚本开头调用 `useApi("lr")` 或 `useApi("cd")`。这两个
命名空间只用于迁移既有脚本，不建议作为新脚本的接口选择；所需旧接口应按实际脚本单独验证。
它们的后续兼容映射独立维护，不会改变默认 `m` API 的参数或返回值。

## 扩展开发

C/C++ 插件、函数表和 ImGui C ABI 的对应关系见「扩展开发」分类。它面向需要直接链接引擎或
编写插件的开发者；普通 Lua 脚本不需要调用 C ABI。

### Android 本地扩展文件

可选 native 运行时和数据文件统一放在平铺目录 `/sdcard/xiaoyv/extensions/`。App 的“扩展”页会
显示其中最外层的全部普通文件；点击某行“导入”仅把该文件以原文件名复制到 App 私有目录，不会执行
代码，也不检查文件名、内容、签名、CPU ABI 或依赖。

具体功能会在脚本实际使用时请求自己的文件，例如 OpenCV、RapidOCR 和 YOLO；它们需要的文件名和
加载时机见各自功能页。改名、放错 CPU 版本或缺少依赖时，错误在运行时由加载器直接反馈。仅完成
导入不会使任意 native 文件自动变成脚本函数；用户自定义扩展的公开加载方式仍需在相应 API 正式
发布后使用。

`io`、`os.date`、`os.time` 等已经由 Lua 5.4 标准库提供，不再包装一份同名实现。
`systemTime()` 返回毫秒时间戳，`tickCount()` 返回当前脚本运行时长，
`getNetWorkTime()` 通过网络时间服务器取得格式化时间。

不会复制旧产品专属的悬浮控制栏事件、配置面板或插件生命周期。相同用途请使用小鱼精灵现有
的 `dialog`、`hud`、`web`、`ui` 和 `imgui`；不存在真实实现的接口不会提供空操作占位。
