小鱼精灵启动脚本时默认启用自己的 `m` API，并把它的一级成员导出为全局函数或表。因此日常
脚本直接写函数名即可：

```lua
appIsFront("com.tencent.mm")
runApp("com.tencent.mm")
screen.capture("/sdcard/xiaoyv/scripts/current.png")
dialog.alert("提示", "脚本已启动")
```

`m` 表始终保留。需要明确归属、避免自定义变量重名，或在插件代码中调用时，可以使用完全等价
的显式写法：

```lua
m.appIsFront("com.tencent.mm")
m.runApp("com.tencent.mm")
m.screen.capture("/sdcard/xiaoyv/scripts/current.png")
m.dialog.alert("提示", "脚本已启动")
```

`m.sleep`、`m.systemTime`、`m.tickCount`、`m.touchDown` 等同名成员与默认全局函数的参数、
返回值一致；`m.ime` 是正式输入法模块，默认全局 `ime` 指向同一张表。`m.html` 是 `m.web`
的别名。设备和应用能力统一归属 `m`，完整清单见左侧「设备」分类。

`useApi("lr")` 与 `useApi("cd")` 可把懒人精灵或触动精灵的兼容成员导出到全局环境。建议
放在脚本开头、业务代码之前调用；`m`、`lr`、`cd` 三个命名空间表不会因切换而消失。切换不
检查同名全局变量，脚本作者自行处理刻意覆盖后的调用语义。

`lr` / `cd` 用于迁移懒人精灵或触动精灵的既有脚本。它们与默认 `m` API 独立维护，不能据此
推断新脚本的参数或返回值；新项目请保持默认 `m`。扩展能力按左侧的网络、输入、图像、找色、
设备、运行时、无障碍和扩展开发分类查看。
