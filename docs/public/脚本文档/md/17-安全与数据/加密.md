**方法名称：** 二进制 AES、RSA 加密接口。

**语法：** `cryptLib.方法名(...)`

**参数说明：**

| 方法 | 参数 | 说明 |
|---|---|---|
| `aes_crypt(data, key, operation[, mode[, iv[, padding]]])` | 二进制字符串、操作和可选配置 | `operation` 为 `"encrypt"` 或 `"decrypt"`；`mode` 默认为 `"cbc"` |
| `aes_keygen(keyLength)` | `keyLength: integer` | 生成 `16`、`24` 或 `32` 字节 AES 密钥 |
| `aes_ivgen()` | 无 | 生成 16 字节 IV |
| `rsa_generate_key([keyBits])` | `keyBits: integer?` | 默认 2048 位，允许 1024～4096 间的 256 倍数 |
| `rsa_encrypt(data, key, isPublicKey)` | 二进制数据、PEM 密钥、布尔值 | `true` 使用公钥，`false` 使用私钥 |
| `rsa_decrypt(data, key, isPublicKey)` | 二进制数据、PEM 密钥、布尔值 | `true` 使用公钥，`false` 使用私钥 |

| 返回值 | 说明 |
|---|---|
| `string` | AES 密钥、IV、密文或明文均以 Lua 二进制字符串返回。 |
| `string, string` | `rsa_generate_key` 返回 `publicKey, privateKey` 两段 PEM。 |

**详细说明：**

AES 支持 `ecb`、`cbc`、`cfb`、`ofb`、`ctr`；除 ECB 外 IV 必须为 16 字节。`padding`
省略或为 `true` 时使用 PKCS#7。RSA 使用 PKCS#1 v1.5 填充。参数无效或平台加密失败会抛出
Lua 错误，不会返回截断数据。

```lua
local key = cryptLib.aes_keygen(32)
local iv = cryptLib.aes_ivgen()
local encrypted = cryptLib.aes_crypt("hello", key, "encrypt", "cbc", iv, true)
local plain = cryptLib.aes_crypt(encrypted, key, "decrypt", "cbc", iv, true)
print(plain)
```
