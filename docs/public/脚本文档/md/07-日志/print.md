**方法名称：** 输出日志。

**语法：** `print(...)` / `printEx(...)`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `...` | `any` | 否 | 可继续传入任意数量的附加参数。 |

| 返回值 | 说明 |
|---|---|
| 无 | 此方法不返回值。 |

**使用示例：**

```lua
print()
```

**详细说明：**

输出到引擎日志。`printEx(...)` 是兼容入口，与 `print(...)` 使用同一套日志输出行为。
这两个入口接受任意数量的 Lua 值，不返回结果，并受 `setLogOff(true)` 控制。

对应 C ABI：`engine_print`。
