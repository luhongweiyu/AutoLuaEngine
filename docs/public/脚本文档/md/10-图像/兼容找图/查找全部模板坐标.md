**方法名称：** 查找一个模板的全部非重叠坐标。

**语法：** `findPicAllPoint(x1, y1, x2, y2, name[, similarity])`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `x1, y1, x2, y2` | `integer` | 是 | 查找区域；四个值都为 `0` 时使用完整屏幕。 |
| `name` | `string` | 是 | 单个模板路径。 |
| `similarity` | `number?` | 否 | 匹配比例，范围 `0` 到 `1`，默认 `1`。 |

| 返回值 | 说明 |
|---|---|
| `table` | 成功时返回 `{ {x=..., y=...}, ... }`；未命中时为空 table。 |
| `nil, string` | 模板读取、参数或截图处理失败时返回原因。 |

**详细说明：**

结果坐标是模板左上角，且每一次命中都会跳过该模板覆盖区域，因此返回的坐标互不重叠。该接口
使用兼容找图的左上扫描顺序；需要小鱼原生 `1..8` 扫描方向时使用 `findPicAll`。

```lua
local points, errorMessage = findPicAllPoint(0, 0, 0, 0, "images/star.png", 0.95)
assert(points, errorMessage)

for _, point in ipairs(points) do
    print(point.x, point.y)
end
```
