returns: "string, integer, integer 或 nil, -1, -1"

**方法名称：** 按给定顺序查找多个模板。

**语法：** `findPicEx(x1, y1, x2, y2, names[, similarity])` 或
`findImage(x1, y1, x2, y2, names[, similarity])`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `x1, y1, x2, y2` | `integer` | 是 | 查找区域；四个值都为 `0` 时使用完整屏幕。 |
| `names` | `string` | 是 | 模板名列表，以 `|` 或空白分隔；按写入顺序依次查找。 |
| `similarity` | `number?` | 否 | 匹配比例，范围 `0` 到 `1`，默认 `1`。 |

| 返回值 | 说明 |
|---|---|
| `string, integer, integer` | 找到时依次返回命中的模板名、左上角 `x`、`y`。 |
| `nil, -1, -1` | 所有模板都未命中。 |

**详细说明：**

`findImage` 是 `findPicEx` 的完整别名。透明 PNG 的透明像素不参与匹配；模板路径支持脚本目录、
绝对路径和当前 `.alpkg` 资源路径。此兼容接口使用方向 `0`（左上开始），不额外传方向参数。

```lua
local name, x, y = findPicEx(
    0, 0, 0, 0,
    "images/start.png|images/continue.png",
    0.95
)

if name then
    print("命中", name, x, y)
end
```
