# 兼容找图

这里是 `m.findPic` 之外的多模板兼容入口。它们使用当前截图来源，支持触控章节的虚拟坐标；
因此启用 `setScreenScale(true, width, height)` 后，传入和返回的坐标都按虚拟分辨率换算。

| 接口 | 用途 |
|---|---|
| [多模板找图](多模板找图.md) | 按模板列表顺序返回第一处命中的名称和坐标。 |
| [查找全部模板坐标](查找全部模板坐标.md) | 返回一个模板的全部非重叠坐标。 |
| [快速多模板找图](快速多模板找图.md) | 按模板列表返回首个有命中的索引和全部坐标。 |

新脚本只需要一个模板时优先使用「模板找图」中的 `findPic` 或 `findPicAll`；这些接口用于迁移
多模板脚本时的名称、方向与返回值习惯。
