---
params: "x1, y1, x2, y2: integer, names: string, deltaColor: string?, direction: integer?, similarity: number?"
returns: "integer, table"
---

**方法名称：** 查找首个有命中的模板并返回其全部坐标。

**语法：** `findPicFast(x1, y1, x2, y2, names[, deltaColor[, direction[, similarity]]])`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `x1, y1, x2, y2` | `integer` | 是 | 查找区域；四个值都为 `0` 时使用完整屏幕。 |
| `names` | `string` | 是 | 模板名列表，以 `|` 或空白分隔。 |
| `deltaColor` | `string?` | 否 | RGB 单通道容差，例如 `"101010"`；默认无额外容差。 |
| `direction` | `integer?` | 否 | `0` 左上、`1` 从中心向外、`2` 右下、`3` 左下、`4` 右上；默认 `0`。 |
| `similarity` | `number?` | 否 | 匹配比例，范围 `0` 到 `1`，默认 `1`。 |

| 返回值 | 说明 |
|---|---|
| `integer, table` | 找到时返回模板在 `names` 中从 `0` 开始的索引，以及该模板全部非重叠坐标。 |
| `-1, {}` | 所有模板都未命中。 |

**详细说明：**

模板按 `names` 的顺序查找，命中第一个模板后不再继续检查后续模板。`direction = 1` 时，返回的
坐标按距离查找区域中心由近到远排序；其他方向按对应扫描顺序返回。

```lua
local index, points = findPicFast(
    0, 0, 0, 0,
    "images/a.png|images/b.png",
    "101010",
    1,
    0.95
)

if index >= 0 then
    print("模板索引", index, "命中数", #points)
end
```
