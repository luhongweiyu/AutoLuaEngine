# OpenCV 概述

本分类先提供与懒人精灵 `luaopenov` 对齐的 `cv.*` 接口：截图 `Mat`、Point/Point2f 和基础数值
指针。每一组函数单独成页，便于按实际调用查找。

| 接口组 | 用途 |
|---|---|
| [`cv.snapShot`](snapShot.md) | 从当前截图缓存创建 OpenCV `Mat`。 |
| [`cv.Point`](Point.md) | 创建、读取和修改整数坐标值指针。 |
| [`cv.Point2f`](Point2f.md) | 创建、读取和修改浮点坐标值指针。 |
| [`cv.Int`](Int.md) / [`cv.Double`](Double.md) / [`cv.Float`](Float.md) | 创建、读取和修改基础数值指针。 |
| [`cv.Long`](Long.md) / [`cv.Byte`](Byte.md) | 创建、读取和修改 64 位整数或字节指针。 |
| [`cv.deletePtr`](deletePtr.md) | 立即使 `cv.new*` 创建的值指针失效。 |

## 使用 OpenCV 算法

Android 包中使用 OpenCV 4.9.0 AAR。它的底层算法是原生 OpenCV；脚本通过现有
[`import`](../../03-Java/import.md) 访问 AAR 提供的 Java 绑定，而不是直接调用 C++ ABI。
例如：

```lua
import("org.opencv.core.*")
import("org.opencv.imgproc.*")

local rgba = cv.snapShot(0, 0, 0, 0)
if rgba then
    local gray = Mat()
    Imgproc.cvtColor(rgba, gray, Imgproc.COLOR_RGBA2GRAY)
    print(gray:cols(), gray:rows())
    gray:release()
    rgba:release()
end
```

`Mat` 和其他 Java OpenCV 对象使用完后应调用其 `release()`。具体算法、类和参数以
[OpenCV 4.9.0 Java API 文档](https://docs.opencv.org/4.9.0/javadoc/)为准；`cv.new*` 值指针不是
Java `Point` 或 `Mat` 的替代品，也不构成完整 C++ OpenCV/FFI 绑定。
