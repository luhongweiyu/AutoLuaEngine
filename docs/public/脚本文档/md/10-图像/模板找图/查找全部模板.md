---
params: "x1, y1, x2, y2: integer, picName: string, deltaColor: string, dir: integer, sim: number"
returns: "table 或 nil, string"
---

**方法名称：** 查找模板图片的全部非重叠命中。

**语法：** `findPicAll(x1, y1, x2, y2, picName, deltaColor, dir, sim)`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `x1, y1, x2, y2` | `integer` | 是 | 查找区域两个角的坐标。 |
| `picName` | `string` | 是 | 模板路径或当前脚本包内资源路径。 |
| `deltaColor` | `string` | 是 | RGB 单通道容差，例如 `"101010"`。 |
| `dir` | `integer` | 是 | 扫描方向 `1..8`，与 `findPic` 一致。 |
| `sim` | `number` | 是 | 匹配比例，范围 `(0, 1]`。 |

| 返回值 | 说明 |
|---|---|
| `table` | 成功返回 `{ {x=..., y=...}, ... }`；未命中时为空 table。 |
| `nil, string` | 参数、截图或模板处理失败时返回错误信息。 |

**详细说明：**

每次命中后会跳过该模板覆盖的区域，因此结果互不重叠。坐标是模板左上角，扫描顺序由
`dir` 决定。模板解析、透明像素和缓存规则与 `findPic` 完全一致。

```lua
local points, errorMessage = findPicAll(
    0, 0, 1079, 1919,
    "images/star.png",
    "101010",
    2,
    0.95
)

if points then
    for _, point in ipairs(points) do
        print(point.x, point.y)
    end
else
    print(errorMessage)
end
```
