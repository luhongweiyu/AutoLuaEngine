# 图像概述

图像、找色、模板找图和 OpenCV 共用当前截图来源。默认来源是带时间缓存的物理屏幕；
`setScreenPixels(imagePath)` 可切换为固定图片，`restoreScreenPixels()` 再切回物理屏幕。
同一帧需要被多次使用时，先锁帧，再完成处理。

| 子分类 | 适用场景 | 入口 |
|---|---|---|
| 截图来源与缓存 | 读取当前点阵、固定图片屏幕、锁帧与刷新间隔 | [截图与缓存](截图与缓存/缓存规则.md) |
| 保存截图 | 把当前全图或区域写入图片文件 | [保存截图](截图输出/保存截图.md) |
| 模板找图 | 单模板、全部命中和模板缓存 | [模板找图](模板找图/查找模板.md) |
| 兼容找图 | 多模板、全部坐标与快速多模板接口 | [兼容找图](兼容找图/概述.md) |
| OpenCV | `Mat` 截图、值指针兼容接口和 Java OpenCV API | [OpenCV](OpenCV/概述.md) |

图片路径和模板路径均支持脚本目录相对路径、共享存储绝对路径或 `file://` 路径，以及当前
`.alpkg` 中声明的资源路径。普通脚本保存的图片可直接交给 `m.ocr.read` 或 `m.ocr.findText`。
