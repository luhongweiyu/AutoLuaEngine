**方法名称：** 坐标缩放与触控手势。

**语法：** `setScreenScale(...)`、`touchDown(...)`、`tap(...)`、`swipe(...)`。

**参数说明：**

| 方法 | 参数 | 返回值 |
|---|---|---|
| `setScreenScale(enabled[, width, height])` | `enabled: boolean`；启用时传基准宽高 | 无 |
| `touchDown([id,] x, y)` | 可选手指 ID 和按下坐标 | 无 |
| `touchMove([id,] x, y)` | 可选手指 ID 和移动坐标 | 无 |
| `touchUp([id,] x, y)` | 可选手指 ID 和抬起坐标 | 无 |
| `tap(x, y[, duration])` | 坐标、可选按住毫秒数，默认 `30` | 无 |
| `longTap(x, y[, duration])` | 坐标、可选按住毫秒数，默认 `500` | 无 |
| `touchMoveEx(id, x, y, duration)` | 手指 ID、终点和毫秒时长 | 无 |
| `swipe(x1, y1, x2, y2[, duration])` | 起止坐标、可选毫秒时长 | 无 |

| 返回值 | 说明 |
|---|---|
| 无 | 这组操作不返回内部触控注入状态。 |

**详细说明：**

`setScreenScale(true, width, height)` 启用虚拟坐标；`setScreenScale(false)` 关闭。启用后本章
触控，以及找色分类中的兼容接口使用虚拟坐标；小鱼原生 `m.findColors`、
`m.findPic` 和 `m.font.*` 仍按其各自的原生坐标契约执行。底层始终在真实屏幕和真实截图上运行。

`touchDown`、`touchMove`、`touchUp` 的手指 ID 可以省略，省略时为 `1`；抬起时必须提供终点
坐标。`touchUp(...)` 会先移动到给定终点，再抬起该手指。

```lua
setScreenScale(true, 1080, 1920)

-- 省略手指 ID，使用默认手指 1。
touchDown(540, 960)
sleep(30)
touchMove(560, 940)
touchUp(560, 940)

-- 多指时显式指定手指 ID。
touchDown(2, 200, 1500)
touchMoveEx(2, 800, 500, 300)
touchUp(2, 800, 500)

tap(540, 960, 40)
longTap(540, 960, 800)
swipe(200, 1500, 800, 500, 400)
setScreenScale(false)
```
