# 无障碍节点自动化

无障碍 API 分为选择器、查询、节点信息、节点动作和节点库五组。它们共用 selector/node 对象，
但参数、返回值和生命周期并不相同，因此分别成页；同一组中仅保留调用方式和返回规则一致的相关方法。

| 页面 | 内容 |
|---|---|
| [选择器](选择器.md) | 按文本、ID、属性和区域组合筛选条件。 |
| [查询与选择器动作](查询与选择器动作.md) | 查找一个或多个节点，或直接点击匹配节点。 |
| [节点信息](节点信息.md) | 读取节点字段、区域和父子关系。 |
| [节点动作](节点动作.md) | 点击、滚动、输入文本、选择和进度操作。 |
| [节点库](节点库.md) | 开关无障碍、导出 XML 和锁定查询树。 |

选择器可以链式组合，每一步返回新的 selector，不会修改原对象。查询依赖已经启用并连接的
小鱼精灵无障碍服务；节点对象持有短期句柄，界面刷新后应重新查询，不要跨界面长期缓存。

```lua
nodeLib.openAccessibility()

local button = text("确定")
    :className("android.widget.Button")
    :findOne(3000)

if button then
    button:click()
end
```
