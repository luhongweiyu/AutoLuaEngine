returns: "node、node 数组、boolean 或 nil"

**方法名称：** 查询选择器匹配的节点或直接操作匹配节点。

**语法：** `selector:findOne([timeout])`、`selector:findAll([timeout])`、`selector:findOnce(index[, timeout])`、`selector:click()`、`selector:longClick()`

**参数说明：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `timeout` | `integer`（可选） | 等待匹配的毫秒数；省略或传 `0` 时只查询当前节点树。 |
| `index` | `integer` | `findOnce` 的匹配序号，从 `0` 开始。负数按 `0` 处理。 |

| 返回值 | 说明 |
|---|---|
| node 或 `nil` | `findOne`、`findOnce` 返回匹配节点；没有匹配时返回 `nil`。 |
| node 数组 | `findAll` 返回全部匹配节点，没有匹配时返回空表。 |
| `boolean` | `click`、`longClick` 返回是否至少成功操作一个匹配节点。 |

**详细说明：**

查询期间会按选择器全部条件匹配当前活动窗口节点树。节点句柄只适合当前界面操作；界面变化后应重新
查询。选择器动作不返回节点，适合不需要读取节点信息的直接点击和长按。

```lua
local itemSelector = textContains("设置"):clickable(true)
local first = itemSelector:findOne(2000)
local all = itemSelector:findAll()

if first then
    first:click()
end
print("匹配数量", #all)
```
