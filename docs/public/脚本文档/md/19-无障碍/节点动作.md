params: "text、row、column、startIndex、endIndex 或 position（按动作）"
returns: "boolean"
---

**方法名称：** 对查询到的无障碍节点执行动作。

**语法：** `node:click()`、`node:setText(text)`、`node:scrollTo(row, column)`、`node:setSelection(startIndex, endIndex)`、`node:setProgress(position)`

**参数说明：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `text` | 任意值 | `setText` 的文本内容；会转换为字符串，`nil` 转为空字符串。 |
| `row, column` | `integer` | `scrollTo` 的目标行和列；省略值按 `0`。 |
| `startIndex, endIndex` | `integer` | `setSelection` 的文本选择起止位置。 |
| `position` | `number` | `setProgress` 的目标进度。 |

| 返回值 | 说明 |
|---|---|
| `boolean` | Android 无障碍节点是否接受并成功执行该动作。 |

**详细说明：**

无参数动作包括 `scrollUp`、`scrollDown`、`scrollLeft`、`scrollRight`、`scrollForward`、
`scrollBackward`、`click`、`longClick`、`focus`、`clearFocus`、`copy`、`paste`、`cut`、
`select`、`collapse`、`expand` 和 `contextClick`。

带参数动作包括 `setText`、`scrollTo`、`setSelection` 和 `setProgress`。动作能否成功取决于目标节点
是否支持对应的 Android 无障碍动作；返回 `false` 时不会自动尝试其他输入方式。

```lua
local input = className("android.widget.EditText"):findOne(2000)
if input then
    input:focus()
    assert(input:setText("小鱼精灵"))
    input:setSelection(0, 2)
end
```
