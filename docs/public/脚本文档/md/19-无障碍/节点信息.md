params: "无"
returns: "string、integer、node、node 数组或坐标"

**方法名称：** 读取无障碍节点字段、区域和关系。

**语法：** `node:text()`、`node:bounds()`、`node:childs()`、`node:parent()`、`node:toJson()`

**参数说明：** 无。

| 返回值 | 说明 |
|---|---|
| `string` | `id`、`text`、`desc`、`className`、`packageName` 或 `toJson` 的结果。 |
| `integer` | `childCount`、`drawingOrder`、`depth` 的结果。 |
| `left, top, right, bottom` | `bounds`、`boundsInParent` 返回四个整数。 |
| node 数组 | `childs` 返回直接子节点。 |
| node 或 `nil` | `parent` 返回父节点；根节点没有父节点时返回 `nil`。 |

**详细说明：**

字段方法包括 `id`、`text`、`desc`、`className`、`packageName`、`childCount`、`drawingOrder` 和
`depth`。`bounds` 是屏幕坐标，`boundsInParent` 是相对父节点的区域。`toJson` 会读取当前句柄
对应节点的完整结构文本。

节点来自短期句柄。应用界面刷新、无障碍服务断开或脚本结束后，旧节点可能失效；需要继续操作时应
重新执行选择器查询。

```lua
local node = id("android:id/title"):findOne()
if node then
    local left, top, right, bottom = node:bounds()
    print(node:text(), left, top, right, bottom)
    print(node:toJson())
end
```
