**方法名称：** 控制无障碍服务、导出节点树和锁定查询根节点。

**语法：** `nodeLib.getNodeXml()`、`nodeLib.saveNode(path)`、`nodeLib.lockNode()`、`nodeLib.unlockNode()`、`nodeLib.openAccessibility()`、`nodeLib.closeAccessibility()`

**参数说明：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `path` | `string` | 保存节点 XML 的完整文件路径；父目录不存在时会尝试创建。 |

| 返回值 | 说明 |
|---|---|
| `string` 或 `nil` | `getNodeXml` 返回当前查询根节点的 XML；当前没有节点树时返回 `nil`。 |
| `boolean` | 其他方法返回操作是否成功。 |

**详细说明：**

| 方法 | 说明 |
|---|---|
| `getNodeXml` | 将当前查询根节点序列化为 XML。 |
| `saveNode` / `saveNodeNew` | 将 XML 覆盖写入指定路径；`saveNodeNew` 是同一实现的兼容别名。 |
| `lockNode` | 保存当前活动窗口根节点，后续查询和 XML 导出使用该快照。再次调用会替换旧快照。 |
| `unlockNode` | 释放已锁定快照，后续查询重新读取当前活动窗口。 |
| `openAccessibility` | 服务已连接时返回 `true`；无法自动启用时打开系统无障碍设置并返回 `false`。 |
| `closeAccessibility` | 关闭本应用无障碍服务并返回是否成功。 |

锁定的是无障碍节点树快照，不是屏幕图像。使用结束后应及时调用 `unlockNode()`；脚本结束时平台也会
清理本次脚本持有的节点快照和句柄。

```lua
if nodeLib.openAccessibility() then
    nodeLib.lockNode()
    local xml = nodeLib.getNodeXml()
    print(xml or "当前没有节点树")
    nodeLib.unlockNode()
end
```
