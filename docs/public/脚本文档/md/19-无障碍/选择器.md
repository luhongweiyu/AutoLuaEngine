params: "value: string|boolean|integer；left, top, right, bottom: integer"
returns: "selector"
---

**方法名称：** 创建和组合无障碍节点选择器。

**语法：** `text(value)`、`selector:id(value)`、`clickable(value)`、`bounds(left, top, right, bottom)`

**参数说明：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `value` | `string` | 字符串选择器的目标内容；正则匹配使用 Java 正则表达式。 |
| `value` | `boolean` | 布尔选择器要求的属性值。 |
| `value` | `integer` | `drawingOrder`、`depth` 或 `index` 的目标整数。 |
| `left, top, right, bottom` | `integer` | `bounds` 或 `boundsInside` 使用的屏幕区域。 |

| 返回值 | 说明 |
|---|---|
| selector | 新的选择器对象，可以继续链式添加条件或执行查询。 |

**详细说明：**

选择器既可以作为全局函数创建，也可以在已有 selector 上链式调用。每次调用都会复制现有条件并
返回新对象，不会修改原选择器。

| 类别 | 方法 |
|---|---|
| 字符串精确匹配 | `id`、`text`、`desc`、`className`、`packageName` |
| 字符串模糊匹配 | 上述名称加 `Contains`、`StartsWith`、`EndsWith`、`Matches` |
| 布尔属性 | `visibleToUser`、`selected`、`clickable`、`longClickable`、`enabled`、`password`、`scrollable`、`checked`、`checkable`、`focusable`、`focused` |
| 整数属性 | `drawingOrder`、`depth`、`index` |
| 区域 | `bounds`、`boundsInside` |

`bounds` 要求节点屏幕区域与参数一致；`boundsInside` 要求节点区域位于参数区域内。

```lua
local confirmButton = text("确定")
    :className("android.widget.Button")
    :clickable(true)
    :boundsInside(0, 0, 1080, 1920)
```
