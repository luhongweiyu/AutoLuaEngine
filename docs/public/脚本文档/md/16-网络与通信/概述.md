# 网络与通信概述

网络能力分为两组：项目 HTTP、文件传输和 WebSocket 是面向脚本的直接接口；LuaSocket 3.1.0
保留上游模块形状，适合 TCP、UDP 和自定义协议。

| 子分类 | 适用场景 | 入口 |
|---|---|---|
| 项目 HTTP | 简单 GET、POST、异步请求、下载和上传 | [HTTP GET](项目HTTP/HTTP%20GET.md) |
| WebSocket | 事件回调式长连接 | [创建 WebSocket](WebSocket/创建%20WebSocket.md) |
| LuaSocket | 同步 TCP/UDP、HTTP 和上游辅助模块 | [LuaSocket 概述](LuaSocket/概述.md) |

项目 HTTP 默认超时为 30 秒，响应正文均以 Lua 字符串返回。`httpGet`、`httpPost`、下载、上传和
WebSocket 不依赖 `require("socket")`。需要低层 socket 时再使用 LuaSocket，并为连接、发送和
接收设置合理超时，避免脚本长期阻塞。
