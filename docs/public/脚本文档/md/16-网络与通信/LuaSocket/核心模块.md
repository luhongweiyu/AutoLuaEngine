**方法名称：** 加载 LuaSocket 核心模块。

**语法：** `local socket = require("socket")`

**参数说明：** 无。

| 返回值 | 说明 |
|---|---|
| `table` | LuaSocket 核心模块，包含 `tcp`、`udp`、`select`、`gettime`、`sleep` 和 `dns` 等入口。 |

**详细说明：**

`socket` 是上游 LuaSocket 3.1.0 核心模块。TCP 和 UDP 的创建方式分别见本分类的专页；`socket.select`
可等待多个 socket 的可读/可写状态，`socket.gettime()` 返回秒级高精度时间，`socket.sleep(seconds)`
阻塞当前调用线程，`socket.dns` 提供 DNS 查询。

```lua
local socket = require("socket")
print(socket.gettime())

local readable, writable = socket.select({}, {}, 0.1)
print(#readable, #writable)
```
