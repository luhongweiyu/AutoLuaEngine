# LuaSocket 3.1.0

Android 运行时内置固定版本的 LuaSocket 3.1.0。它保留上游的 `require` 模块和同步 socket 语义，
不额外包装为 `m.http` 或其他项目私有命名空间。

| 模块 | 用途 | 文档 |
|---|---|---|
| `socket` | TCP、UDP、`select`、时间与 DNS 工具 | [核心模块](核心模块.md) |
| `socket.http` | 标准 LuaSocket HTTP 请求 | [HTTP 请求](HTTP%20请求.md) |
| `ssl.https` | HTTPS 请求兼容入口 | [HTTPS 请求](HTTPS%20请求.md) |
| `ltn12` | source、sink、filter、pump 数据流组合 | [LTN12](LTN12.md) |
| `mime` | Base64、quoted-printable 等编码工具 | [MIME](MIME.md) |
| `socket.url` | URL 解析、构建与转义 | [URL](URL.md) |
| `socket.ftp` / `socket.smtp` | FTP 与 SMTP 协议模块 | [FTP](FTP.md)、[SMTP](SMTP.md) |

TCP/UDP、`socket.http` 等函数名、参数和返回值遵循
[LuaSocket 3.1.0 上游源码](https://github.com/lunarmodules/luasocket/tree/v3.1.0)。`socket.tp` 和
`socket.headers` 也随上游模块提供，主要作为 HTTP、FTP、SMTP 的支持模块，通常不需要直接调用。

LuaSocket 本身不包含 LuaSec TLS socket。为了让常见 HTTPS 脚本可用，`ssl.https.request(...)` 和
`socket.http.request(...)` 的 HTTPS URL 会使用项目 HTTPS 请求通道；它们保持请求形状，但不提供
`ssl.https.tcp` 等 TLS socket API。
