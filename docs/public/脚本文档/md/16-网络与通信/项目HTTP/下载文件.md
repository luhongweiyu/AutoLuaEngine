**方法名称：** 下载 HTTP 文件到本地路径。

**语法：** `downloadFile(url, savePath[, progress])`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `url` | `string` | 是 | 要下载的 HTTP 或 HTTPS 地址。 |
| `savePath` | `string` | 是 | 最终文件路径；不存在的父目录会自动创建。 |
| `progress` | `function?` | 否 | 下载成功后调用一次 `progress(100)`。 |

| 返回值 | 说明 |
|---|---|
| `true` | 文件完整下载并写入目标路径。 |
| `false, string` | 下载、路径创建或写入失败时返回原因。 |

**详细说明：**

下载时会在 `savePath` 同一目录创建形如 `文件名.part.唯一值` 的临时文件。只有成功接收 HTTP 2xx
响应并完整写入后，才用临时文件替换 `savePath`；下载或写入失败会删除临时文件并保留已有目标文件。
底层文件系统支持时，最后的替换为原子操作。当前 `progress` 只提供完成通知，不提供分段进度。
调用会同步等待完成。

```lua
local ok, errorMessage = downloadFile(
    "https://example.com/data.zip",
    "/sdcard/xiaoyv/data.zip",
    function(percent) print(percent .. "%") end
)
assert(ok, errorMessage)
```
