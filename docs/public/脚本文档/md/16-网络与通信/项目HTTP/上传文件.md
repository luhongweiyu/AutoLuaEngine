returns: "string, integer 或 nil, string"

**方法名称：** 以 multipart 表单上传一个文件。

**语法：** `uploadFile(url, filePath[, timeout])`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `url` | `string` | 是 | 上传地址。 |
| `filePath` | `string` | 是 | 要上传的普通本地文件路径。 |
| `timeout` | `number?` | 否 | 超时秒数，默认 `30`。 |

| 返回值 | 说明 |
|---|---|
| `string, integer` | 成功发起请求时返回响应正文和 HTTP 状态码。 |
| `nil, string` | 文件不存在、网络或请求失败时返回原因。 |

**详细说明：**

文件使用 `multipart/form-data` 的 `file` 字段上传，文件名取自 `filePath` 的最后一段。HTTP 非 2xx
响应仍会返回正文和状态码，便于由脚本处理服务端错误。

```lua
local body, code = uploadFile(
    "https://example.com/upload",
    "/sdcard/xiaoyv/report.txt",
    30
)
assert(body, code)
print(code, body)
```
