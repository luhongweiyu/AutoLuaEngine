---
params: "name, labelsPath, paramPath, binPath: string, loadOptions: table?"
returns: "boolean 或 nil, string"
---

**方法名称：** 加载或复用一个命名 YOLOv5 NCNN 模型。

**语法：** `m.yolo.load(name, labelsPath, paramPath, binPath[, loadOptions])`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `name` | `string` | 是 | 当前 Worker 中使用的模型名称，不能为空。 |
| `labelsPath` | `string` | 是 | 标签文件路径，每行对应一个类别。 |
| `paramPath` | `string` | 是 | NCNN `.param` 文件路径。 |
| `binPath` | `string` | 是 | NCNN `.bin` 权重文件路径。 |
| `loadOptions` | `table?` | 否 | 模型图结构和运行方式；省略时使用默认值。 |

`loadOptions`：

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `input` | `string` | `"images"` | 输入 blob 名称。 |
| `outputs` | `string[]` | `{"output", "353", "367"}` | 必须恰好三个，依次对应 stride 8、16、32 的输出 blob。 |
| `useGpu` | `boolean` | `false` | 当前 CPU 运行时只接受 `false`；`true` 会明确失败。 |

| 返回值 | 说明 |
|---|---|
| `true` | 模型加载成功，或同名同配置模型已经加载。 |
| `nil, string` | 运行库、路径、模型、blob 或 options 无效。 |

**详细说明：**

未知字段或错误类型会失败。相同名称和相同配置重复加载直接复用；同名不同配置不会替换旧模型，
必须先 `release(name)`。

```lua
local ok, errorMessage = m.yolo.load(
    "main",
    "models/coco.txt",
    "models/yolov5s.param",
    "models/yolov5s.bin",
    {
        input = "images",
        outputs = {"output", "353", "367"},
        useGpu = false,
    }
)
assert(ok, errorMessage)
```
