**方法名称：** 查询 YOLO 模型是否已加载。

**语法：** `m.yolo.isLoaded([name])`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `name` | `string?` | 否 | 模型名称；省略时使用 `default`。 |

| 返回值 | 说明 |
|---|---|
| `true` | 指定模型已加载。 |
| `false` | 指定模型未加载。 |
| `nil, string` | 平台调用失败。 |

**详细说明：**

查询不存在的模型不会加载可选 SO。

```lua
if not m.yolo.isLoaded() then
    assert(m.yolo.init("models/coco.txt", "models/yolov5s.param", "models/yolov5s.bin"))
end
```
