returns: "table 或 nil, string"

**方法名称：** 使用默认模型检测屏幕或图片。

**语法：**

```lua
m.yolo.detect()
m.yolo.detect(detectOptions)
m.yolo.detect(imagePath[, detectOptions])
```

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `imagePath` | `string?` | 否 | 省略时检测屏幕；传字符串时检测该普通图片文件。 |
| `detectOptions` | `table?` | 否 | 字段与[检测屏幕](检测屏幕.md)一致；也可作为唯一参数直接传入。 |

| 返回值 | 说明 |
|---|---|
| `table` | `default` 模型的检测项数组。 |
| `nil, string` | 默认模型未加载，或截图、图片、options、推理失败。 |

**详细说明：**

该方法始终使用 `m.yolo.init()` 加载的 `default` 模型：

- 无参数：检测完整当前屏幕。
- 第一个参数是 table：把它作为检测 options，检测完整当前屏幕。
- 第一个参数是 string：把它作为普通图片路径进行检测。

检测 options、返回数组和错误语义与 `detectScreen/detectFile` 相同。该入口不接受 Java
`Bitmap`，也不接受检测期 `useGpu` 开关；GPU 配置只属于模型加载。

```lua
local screenItems = assert(m.yolo.detect({probThreshold = 0.4}))
local fileItems = assert(m.yolo.detect("images/test.jpg", {targetSize = 960}))
```
