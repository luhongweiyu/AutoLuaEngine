**方法名称：** 查询 YOLO 可选运行时信息。

**语法：** `m.yolo.runtimeInfo()`

**参数说明：** 无。

| 返回值 | 说明 |
|---|---|
| `table` | 查询成功。至少包含 `available:boolean` 和 `loaded:boolean`；未加载时还会包含导入文件名、扩展目录和最近加载错误，加载后包含 NCNN 后端信息。 |
| `nil, string` | 平台查询失败。 |

**详细说明：**

该方法不会为了查询状态而加载 SO。`available=true` 只表示固定相对路径的文件已经导入；CPU ABI、
依赖和接口是否正确，要到 `load/init` 时才能确认。

```lua
local info, errorMessage = m.yolo.runtimeInfo()
assert(info, errorMessage)
print("已导入：", info.available)
print("已加载：", info.loaded)
print("后端：", info.backend)
```
