**方法名称：** 查询 YOLO 运行库是否已经导入。

**语法：** `m.yolo.isAvailable()`

**参数说明：** 无。

| 返回值 | 说明 |
|---|---|
| `true` | `yolo/libxiaoyv_yolo.so` 已导入，可以在加载模型时尝试装载。 |
| `false` | 尚未导入；这是正常状态，不是调用失败。 |
| `nil, string` | 查询过程失败。 |

**详细说明：**

该方法不加载 SO，也不保证已导入文件与当前 APK ABI 匹配。需要更多状态时使用
`m.yolo.runtimeInfo()`。

```lua
local available, errorMessage = m.yolo.isAvailable()
assert(available ~= nil, errorMessage)
print("YOLO 运行库已导入：", available)
```
