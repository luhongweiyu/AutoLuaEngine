**方法名称：** 使用命名模型检测普通图片文件。

**语法：** `m.yolo.detectFile(name, imagePath[, detectOptions])`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `name` | `string` | 是 | 已加载的模型名称。 |
| `imagePath` | `string` | 是 | Android 可读取的 PNG、JPEG、WebP 等图片；相对路径基于脚本工作目录。 |
| `detectOptions` | `table?` | 否 | 字段与[检测屏幕](检测屏幕.md)一致。 |

| 返回值 | 说明 |
|---|---|
| `table` | 检测项数组；没有命中时为空数组。 |
| `nil, string` | 模型、图片、options 或推理失败。 |

**详细说明：**

成功返回检测项数组，坐标相对原图片；没有命中时返回空数组。模型未加载、图片无法解码或推理
失败时返回 `nil, errorMessage`。

```lua
local items, errorMessage = m.yolo.detectFile("main", "images/test.jpg")
assert(items, errorMessage)
```
