**方法名称：** 使用命名模型检测当前屏幕。

**语法：**

```lua
m.yolo.detectScreen(name[, detectOptions])
m.yolo.detectScreen(name, left, top, right, bottom[, detectOptions])
```

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `name` | `string` | 是 | 已加载的模型名称。 |
| `left/top/right/bottom` | `integer` | 否 | 左闭右开的检测区域；四个坐标全部省略时检测完整屏幕。 |
| `detectOptions` | `table?` | 否 | 单次检测性能和筛选配置。 |

`detectOptions`：

| 字段 | 类型 | 默认值 | 有效范围 | 说明 |
|---|---|---:|---:|---|
| `targetSize` | `integer` | `640` | `32`～`4096` | 输入长边缩放目标；越大通常越利于小目标，但更慢、更占内存。 |
| `threads` | `integer` | `2` | `1`～`32` | 本次 NCNN CPU 推理线程数。 |
| `probThreshold` | `number` | `0.25` | `0`～`1` | 候选目标最低概率。 |
| `nmsThreshold` | `number` | `0.45` | `0`～`1` | 非极大值抑制阈值。 |

| 返回值 | 说明 |
|---|---|
| `table` | 检测项数组；没有命中时为空数组。 |
| `nil, string` | 截图、模型、区域、options 或推理失败。 |

**详细说明：**

未知字段、错误类型或检测期 `useGpu` 会失败。成功返回检测项数组；区域检测的 `x/y` 仍相对完整
屏幕，而不是裁剪区域。该入口使用当前截图缓存的一份稳定 RGBA 副本。

```lua
local items, errorMessage = m.yolo.detectScreen("main", 0, 0, 1080, 1200, {
    targetSize = 640,
    threads = 2,
    probThreshold = 0.3,
})
assert(items, errorMessage)
```
