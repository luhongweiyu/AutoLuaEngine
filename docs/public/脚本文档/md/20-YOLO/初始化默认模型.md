**方法名称：** 初始化默认 YOLO 模型。

**语法：** `m.yolo.init(labelsPath, paramPath, binPath[, loadOptions])`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `labelsPath` | `string` | 是 | 标签文件路径。 |
| `paramPath` | `string` | 是 | NCNN `.param` 文件路径。 |
| `binPath` | `string` | 是 | NCNN `.bin` 权重文件路径。 |
| `loadOptions` | `table?` | 否 | 与 `m.yolo.load` 相同的加载配置。 |

| 返回值 | 说明 |
|---|---|
| `true` | `default` 模型加载成功或已按同一配置加载。 |
| `nil, string` | 加载失败。 |

**详细说明：**

该方法等价于：

```lua
m.yolo.load("default", labelsPath, paramPath, binPath, loadOptions)
```

参数顺序参考常见的 `labels, param, bin` 调用方式。路径规则、`loadOptions` 字段、模型兼容范围和
同名重复加载语义与[加载模型](加载模型.md)完全相同。`m.yolo.detect()`、省略名称的
`release()` 和 `isLoaded()` 都操作这个固定的 `default` 模型，不会自动选择最后加载的模型。
