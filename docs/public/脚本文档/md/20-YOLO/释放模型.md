**方法名称：** 释放 YOLO 模型。

**语法：** `m.yolo.release([name])`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `name` | `string?` | 否 | 模型名称；省略时使用 `default`。 |

| 返回值 | 说明 |
|---|---|
| `true` | 模型已释放。 |
| `false` | 模型本来就不存在，不视为错误。 |
| `nil, string` | 平台调用失败。 |

**详细说明：**

释放只移除当前 Worker 内的模型对象，不删除 labels、param、bin 或导入的运行库文件。

```lua
m.yolo.release("main")
m.yolo.release() -- 释放 init() 使用的 default 模型
```
