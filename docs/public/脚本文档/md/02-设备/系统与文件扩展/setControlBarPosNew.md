**方法名称：** 设置控制栏位置。

**语法：** `setControlBarPosNew(x, y)`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `x` | `number` | 是 | 相对屏幕宽度的比例。 |
| `y` | `number` | 是 | 相对屏幕高度的比例。 |

| 返回值 | 说明 |
|---|---|
| 无 | 更新控制栏位置。 |

**使用示例：**

```lua
setControlBarPosNew(0.5, 0.1)
```

**详细说明：**

`x`、`y` 使用屏幕宽高的相对比例，范围为 `0` 到 `1`。
