**方法名称：** 扫描图片文件。

**语法：** `scanImage(path)`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `path` | `string` | 是 | 图片文件路径。相对路径按脚本工作目录解析。 |

| 返回值 | 说明 |
|---|---|
| 无 | 请求 Android 媒体库扫描该文件。 |

**使用示例：**

```lua
scanImage("screenshots/result.png")
```

**详细说明：**

该函数用于让系统媒体库发现新生成的图片，不负责保存图片内容。
