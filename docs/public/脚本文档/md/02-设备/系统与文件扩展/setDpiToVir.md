**方法名称：** 设置虚拟屏幕 DPI。

**语法：** `setDpiToVir(dpi)`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `dpi` | `integer` | 是 | 要设置的显示密度。 |

| 返回值 | 说明 |
|---|---|
| 无 | 设置成功；失败时抛出 Lua 错误。 |

**使用示例：**

```lua
setDpiToVir(420)
```

**详细说明：**

该设置影响当前运行环境的显示密度。需要恢复系统值时调用 `setDpiToRealy()`。
