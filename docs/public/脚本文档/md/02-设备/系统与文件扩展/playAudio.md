**方法名称：** 播放音频。

**语法：** `playAudio(path)`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `path` | `string` | 是 | 音频文件路径。相对路径按脚本工作目录解析。 |

| 返回值 | 说明 |
|---|---|
| 无 | 启动音频播放；失败时抛出 Lua 错误。 |

**使用示例：**

```lua
playAudio("notify.mp3")
```

**详细说明：**

重复调用会先停止当前播放，再播放新的文件。需要主动停止时调用 `stopAudio()`。
