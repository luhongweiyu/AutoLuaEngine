**方法名称：** 使用当前字库识别区域文字。

**语法：** `m.ocr(x1, y1, x2, y2, color[, similarity])`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `x1, y1, x2, y2` | `integer` | 是 | 识别区域。 |
| `color` | `string` | 是 | 字形前景颜色规则。 |
| `similarity` | `number?` | 否 | 相似度，范围 `0..1`，默认 `1`。 |

| 返回值 | 说明 |
|---|---|
| `string` | 识别出的文字；没有可识别文字时可为空字符串。 |
| `nil, string` | 截图或字库处理失败时返回原因。 |

**详细说明：**

`m.ocr` 兼容入口是可调用的 `m.ocr` 表，不影响同一表上的 `m.ocr.load`、`m.ocr.read` 等模型 OCR
方法。该入口使用点阵字库，不会加载 ONNX 模型；启用虚拟坐标后，区域坐标会换算到真实截图。

```lua
assert(m.setDict(0, "/sdcard/xiaoyv/scripts/font.txt") == 1)
assert(m.useDict(0) == 1)
local text, errorMessage = m.ocr(0, 0, 300, 100, "FFFFFF", 0.95)
assert(text, errorMessage)
print(text)
```
