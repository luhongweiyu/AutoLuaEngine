params: "x1, y1, x2, y2: integer, text: string, color: string, similarity: number?"
returns: "string"
---

**方法名称：** 查找全部候选文字并返回 JSON 坐标数组。

**语法：** `m.findStrEx(x1, y1, x2, y2, text, color[, similarity])`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `x1, y1, x2, y2` | `integer` | 是 | 查找区域。 |
| `text` | `string` | 是 | 要查找的文字；可用 `|` 分隔多个候选文字。 |
| `color` | `string` | 是 | 字形前景颜色规则。 |
| `similarity` | `number?` | 否 | 相似度，范围 `0..1`，默认 `1`。 |

| 返回值 | 说明 |
|---|---|
| `string` | JSON 数组；每项包含 `x`、`y`、`text`，没有命中时为 `[]`。 |

**详细说明：**

结果会按从上到下、从左到右排序，坐标遵循当前虚拟坐标设置。需要 Lua table 形式时优先使用
`m.font.findStrEx`。

```lua
local json = m.findStrEx(0, 0, 500, 200, "开始|继续", "FFFFFF", 0.95)
print(json)
```
