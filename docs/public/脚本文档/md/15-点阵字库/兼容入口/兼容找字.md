---
params: "x1, y1, x2, y2: integer, text: string, color: string, similarity: number?"
returns: "string, integer, integer 或 nil, -1, -1"
---

**方法名称：** 在当前字库识别结果中查找第一处候选文字。

**语法：** `m.findStr(x1, y1, x2, y2, text, color[, similarity])`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `x1, y1, x2, y2` | `integer` | 是 | 查找区域。 |
| `text` | `string` | 是 | 要查找的文字；可用 `|` 分隔多个候选文字。 |
| `color` | `string` | 是 | 字形前景颜色规则。 |
| `similarity` | `number?` | 否 | 相似度，范围 `0..1`，默认 `1`。 |

| 返回值 | 说明 |
|---|---|
| `string, integer, integer` | 找到时返回命中的候选文字和坐标 `x, y`。 |
| `nil, -1, -1` | 没有候选文字命中。 |

**详细说明：**

候选文字按 `text` 中的顺序逐个检查。该入口会使用当前选中字库；新脚本需要更标准的坐标或错误返回时
优先使用 `m.font.findStr`。

```lua
local matched, x, y = m.findStr(0, 0, 500, 200, "开始|继续", "FFFFFF", 0.95)
if matched then print(matched, x, y) end
```
