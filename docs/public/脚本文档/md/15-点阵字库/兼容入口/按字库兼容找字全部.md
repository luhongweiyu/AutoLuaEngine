---
params: "index: integer, x1, y1, x2, y2: integer, text: string, color: string, similarity: number?"
returns: "string 或 nil, string"
---

**方法名称：** 临时选择字库后查找全部候选文字。

**语法：** `m.findStrExNew(index, x1, y1, x2, y2, text, color[, similarity])`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `index` | `integer` | 是 | 要切换到的字库编号。 |
| `x1, y1, x2, y2` | `integer` | 是 | 查找区域。 |
| `text` | `string` | 是 | 候选文字，可用 `|` 分隔。 |
| `color` | `string` | 是 | 字形前景颜色规则。 |
| `similarity` | `number?` | 否 | 相似度，范围 `0..1`，默认 `1`。 |

| 返回值 | 说明 |
|---|---|
| `string` | JSON 坐标数组；没有命中时为 `[]`。 |
| `nil, string` | 字库选择失败时返回原因。 |

**详细说明：**

该函数先选择 `index`，再调用 `m.findStrEx(...)`。选择成功后，即使没有文字命中也会返回 JSON
数组字符串；调用后当前线程会继续使用该字库。

```lua
local json, errorMessage = m.findStrExNew(0, 0, 0, 500, 200, "开始|继续", "FFFFFF", 0.95)
assert(json, errorMessage)
print(json)
```
