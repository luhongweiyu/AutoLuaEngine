params: "index: integer, x1, y1, x2, y2: integer, color: string, similarity: number?"
returns: "string 或 nil, string"
---

**方法名称：** 临时选择字库后执行兼容识字。

**语法：** `m.ocrNew(index, x1, y1, x2, y2, color[, similarity])` 或
`m.ocrjNew(index, x1, y1, x2, y2, color[, similarity])`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `index` | `integer` | 是 | 要切换到的字库编号。 |
| `x1, y1, x2, y2` | `integer` | 是 | 识别区域。 |
| `color` | `string` | 是 | 字形前景颜色规则。 |
| `similarity` | `number?` | 否 | 相似度，范围 `0..1`，默认 `1`。 |

| 返回值 | 说明 |
|---|---|
| `string` | `ocrNew` 返回文字；`ocrjNew` 返回 JSON 坐标数组。 |
| `nil, string` | 字库选择、截图或识别失败时返回原因。 |

**详细说明：**

两个函数都会先执行 `m.useDict(index)`，成功后分别调用 `m.ocr(...)` 或 `m.ocrj(...)`。它们会改变
当前线程的已选字库；若需要显式控制字库生命周期，优先拆开调用 `m.useDict` 和相应识字函数。

```lua
local text, errorMessage = m.ocrNew(0, 0, 0, 300, 100, "FFFFFF", 0.95)
assert(text, errorMessage)
print(text)
```
