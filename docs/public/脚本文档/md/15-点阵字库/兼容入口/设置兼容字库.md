**方法名称：** 设置一个兼容字库。

**语法：** `m.setDict(index, dictionary)`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `index` | `integer` | 是 | 字库编号。 |
| `dictionary` | `string` | 是 | 字库文本、普通文件路径或当前 `.alpkg` 资源路径。 |

| 返回值 | 说明 |
|---|---|
| `1` | 成功设置字库。 |
| `0, string` | 字库格式、路径或读取失败时返回原因。 |

**详细说明：**

该入口与 `m.font.setDict` 使用同一份当前脚本字库，但保留旧接口的 `1` / `0, errorMessage`
返回值。新脚本优先使用 `m.font.setDict`，迁移旧脚本时再使用本页接口。

```lua
local ok, errorMessage = m.setDict(0, "/sdcard/xiaoyv/scripts/font.txt")
assert(ok == 1, errorMessage)
```
