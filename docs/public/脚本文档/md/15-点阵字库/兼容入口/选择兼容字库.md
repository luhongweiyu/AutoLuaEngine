**方法名称：** 选择当前线程使用的兼容字库。

**语法：** `m.useDict(index)`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `index` | `integer` | 是 | 已通过 `m.setDict` 或 `m.font.setDict` 设置的字库编号。 |

| 返回值 | 说明 |
|---|---|
| `1` | 成功选择字库。 |
| `0, string` | 字库不存在或无法选择时返回原因。 |

**详细说明：**

字库选择属于当前 Lua native 线程。主线程和子线程需要使用同一非默认字库时，应各自在开始时调用一次。
该接口与 `m.font.useDict` 操作同一份字库，区别只在返回值形式。

```lua
assert(m.setDict(2, "/sdcard/xiaoyv/scripts/font.txt") == 1)
assert(m.useDict(2) == 1)
```
