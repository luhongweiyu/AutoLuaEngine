**方法名称：** 使用当前字库识别区域文字并返回 JSON 坐标。

**语法：** `m.ocrj(x1, y1, x2, y2, color[, similarity])`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `x1, y1, x2, y2` | `integer` | 是 | 识别区域。 |
| `color` | `string` | 是 | 字形前景颜色规则。 |
| `similarity` | `number?` | 否 | 相似度，范围 `0..1`，默认 `1`。 |

| 返回值 | 说明 |
|---|---|
| `string` | JSON 数组，每项包含 `x`、`y`、`text`、`w`、`h`、`score`。 |
| `nil, string` | 截图或字库处理失败时返回原因。 |

**详细说明：**

返回坐标会遵循当前虚拟坐标设置。该格式用于兼容旧脚本；需要 Lua table 结果时优先使用
`m.font.read`。

```lua
local json, errorMessage = m.ocrj(0, 0, 300, 100, "FFFFFF", 0.95)
assert(json, errorMessage)
print(json)
```
