**方法名称：** 坐标缩放、触控手势和输入法补充接口。

**语法：** `setScreenScale(...)`、`tap(...)`、`swipe(...)`、`ime.方法名(...)`

**参数说明：**

| 方法 | 参数 | 返回值 |
|---|---|---|
| `setScreenScale(kind[, width, height])` | `kind=0` 关闭；`kind=1` 启用并传虚拟宽高 | `true` |
| `touchDown(id, x, y)` | 手指 ID、坐标 | 无 |
| `touchMove(id, x, y)` | 手指 ID、坐标 | `boolean` |
| `touchUp(id)` | 手指 ID | `boolean` |
| `tap(x, y)` / `longTap(x, y)` | 坐标 | 无 |
| `touchMoveEx(id, x, y, duration)` | 手指 ID、终点、毫秒时长 | 无 |
| `swipe(x1, y1, x2, y2[, duration])` | 起止坐标、毫秒时长 | `boolean` |
| `ime.deleteChar()` | 无 | `boolean` |
| `ime.finishInput()` | 无 | `boolean` |
| `ime.keyEvent(action, keyCode)` | Android 按键 action 和 keyCode | `boolean` |

| 返回值 | 说明 |
|---|---|
| `boolean` | 表示对应触控或输入法操作是否成功提交。 |
| 无 | `touchDown`、`tap`、`longTap` 和 `touchMoveEx` 保持兼容接口的无返回约定。 |

**详细说明：**

启用屏幕缩放后，本章触控接口以及兼容图色、找图、识字接口都使用虚拟坐标；底层仍在真实
截图和真实屏幕上执行。`0,0,0,0` 的全屏区域语义保持不变。输入法补充方法要求小鱼精灵
输入法已经按输入法章节完成锁定或处于可接收命令状态；平台失败会抛出 Lua 错误。

```lua
setScreenScale(1, 1080, 1920)
tap(540, 960)
local ok = swipe(200, 1500, 800, 500, 400)
setScreenScale(0)
print(ok)
```
