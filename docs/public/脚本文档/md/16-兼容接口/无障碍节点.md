**方法名称：** Android 无障碍节点选择、查询和操作接口。

**语法：** `text("确定"):click()`、`nodeLib.getNodeXml()` 等。

**参数说明：**

| 类别 | 方法 | 返回值 |
|---|---|---|
| 字符串选择器 | `id/text/desc/className/packageName(value)` | selector |
| 字符串匹配 | 上述名称加 `Contains`、`StartsWith`、`EndsWith`、`Matches` | selector |
| 布尔选择器 | `visibleToUser/selected/clickable/longClickable/enabled/password/scrollable/checked/checkable/focusable/focused(value)` | selector |
| 整数选择器 | `drawingOrder/depth/index(value)` | selector |
| 区域选择器 | `bounds(l,t,r,b)` / `boundsInside(l,t,r,b)` | selector |
| 查询 | `selector:findOne([timeout])`、`:findAll([timeout])`、`:findOnce(index[, timeout])` | node、node 数组或 `nil` |
| 选择器动作 | `selector:click()` / `selector:longClick()` | `boolean` |
| 节点字段 | `node:id/text/desc/className/packageName/childCount/drawingOrder/depth()` | 字段值 |
| 节点区域 | `node:bounds()` / `node:boundsInParent()` | `left,top,right,bottom` |
| 节点关系 | `node:childs()` / `node:parent()` / `node:toJson()` | node 数组、node 或 JSON 字符串 |
| 节点动作 | 见下方动作表 | `boolean` |
| 节点库 | `nodeLib.getNodeXml/saveNode/lockNode/unlockNode/openAccessibility/closeAccessibility` | 字符串或 `boolean` |

选择器可以链式组合，每一步返回新的 selector，不会修改原对象。`findOnce` 的 `index`
从 `0` 开始。

节点无参数动作包括 `scrollUp`、`scrollDown`、`scrollLeft`、`scrollRight`、
`scrollForward`、`scrollBackward`、`click`、`longClick`、`focus`、`clearFocus`、
`copy`、`paste`、`cut`、`select`、`collapse`、`expand`、`contextClick`。带参数动作包括：

- `node:setText(text)`
- `node:scrollTo(row, column)`
- `node:setSelection(startIndex, endIndex)`
- `node:setProgress(position)`

| 返回值 | 说明 |
|---|---|
| selector / node / `table` | 构造、查询和关系接口按上表返回。 |
| `boolean` | 节点动作和大部分 `nodeLib` 控制接口返回是否成功。 |
| `string` | `getNodeXml`、`toJson` 返回结构文本。 |

**详细说明：**

查询依赖已经启用并连接的小鱼精灵无障碍服务。`timeout` 单位毫秒；省略时只查当前窗口树。
节点对象持有短期句柄，界面刷新后应重新查询，不要长期缓存。正则选择器使用 Java 正则表达式。

```lua
nodeLib.openAccessibility()

local button = text("确定")
    :className("android.widget.Button")
    :findOne(3000)

if button then
    button:click()
end
```
