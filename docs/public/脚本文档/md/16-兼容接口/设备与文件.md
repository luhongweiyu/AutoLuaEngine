**方法名称：** 设备、文件、媒体和脚本控制兼容接口。

**语法：** `zip(...)`、`playAudio(...)`、`setTimer(...)` 等。

**参数说明：**

| 方法 | 参数 | 返回值 |
|---|---|---|
| `printEx(...)` | 任意日志参数 | 无 |
| `setLogOff(disabled)` | 是否关闭普通 `print` | 无 |
| `rnd(first, last)` | 整数上下界 | `integer` |
| `getLrApi()` | 无 | 与 `getXiaoyvApi()` 一致 |
| `getScriptVersion()` | 无 | 工作目录 `version` 文件中的整数 |
| `setSnapCacheTime(ms)` | 毫秒 | 与 `setCaptureCacheMs` 一致 |
| `playAudio(path)` / `stopAudio()` | 音频路径 / 无 | 无 |
| `scanImage(path)` | 图片路径 | 无 |
| `checkIsDebug()` | 无 | `boolean` |
| `zip(source, zipPath)` | 文件或目录、目标 ZIP | 无 |
| `unZip(zipPath, output[, password[, charset]])` | ZIP、输出目录和可选解密参数 | 无 |
| `extractApkAssets(asset, output)` | APK assets 路径、输出路径 | 无 |
| `extractAssets(assetArchive, output[, pattern])` | assets 压缩包、输出目录、通配规则 | 无 |
| `setDpiToVir(dpi)` / `setDpiToRealy()` | DPI / 无 | 无 |
| `showControlBar(show)` / `setControlBarPosNew(x, y)` | 显示状态；`x/y` 为屏幕宽高的 `0–1` 比例 | 无 |
| `restartScript()` | 无 | 无 |
| `setTimer(callback, delay, ...)` | 回调、毫秒和透传参数 | 无 |
| `setStopCallBack(callback)` | `function(error, exitCode)` | 无 |
| `setRootEnvMode(enabled)` | 是否启用 Root 环境 | 无 |
| `setAccessibilityEnvMode()` | 无 | 无 |

| 返回值 | 说明 |
|---|---|
| 无 | 操作型兼容函数成功后不返回值；平台失败会抛出 Lua 错误。 |
| `integer` / `boolean` | `rnd`、`checkIsDebug` 和两个别名按上表返回。 |

**详细说明：**

相对文件路径按当前脚本工作目录解析。`zip` 不允许目标 ZIP 等于源路径，也不允许把目标
放进待压缩目录内部。`unZip` 支持密码和字符集；默认字符集为 UTF-8。

`setTimer` 在独立 Lua 子线程等待后执行回调。`restartScript` 请求当前脚本结束并由宿主按原
启动参数重新运行。控制栏函数操作小鱼精灵现有控制栏，不创建旧产品的事件或配置系统。
`setStopCallBack` 的结束码为 `0` 正常、`1` 主动停止、`2` 运行错误；回调在全部子线程
回收后、Lua 运行时销毁前执行。

```lua
zip("result", "result.zip")
setTimer(function(message)
    print(message)
end, 1000, "timer fired")
```
