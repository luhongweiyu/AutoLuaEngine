# Android Lua 兼容接口

本章集中说明小鱼精灵已经落地的懒人精灵、触动精灵常用接口。默认 `m` 命名空间会把一级
成员导出成同名全局函数；迁移旧脚本时也可以在开头调用 `useApi("lr")` 或
`useApi("cd")`。

| 模块 | 当前入口 | 说明 |
|---|---|---|
| 加密 | `cryptLib.*` | AES、RSA 和安全随机密钥 |
| 网络 | `httpGet`、`httpPost`、WebSocket、`socket.http` | HTTP、文件传输和 LuaSocket 常用请求形状 |
| 标准库 / FFI | `io.*`、`os.*`、`ffi.cdef`、`ffi.load` | Lua 5.4 标准库与受限整数/指针 C ABI |
| 触控与输入法 | `setScreenScale`、`tap`、`swipe`、`ime.*` | 坐标缩放、触控和输入法补充操作 |
| 图色与识字 | `getPixelColor`、`findMultiColor`、`findCircle` 等 | 复用当前截图缓存和点阵字库 |
| OpenCV | `cv.*` | native 值指针与真实 `Mat` 截图 |
| 设备与文件 | `zip`、`playAudio`、`setTimer` 等 | 已有 Android 平台能力的兼容名称 |
| 无障碍节点 | 选择器、节点对象、`nodeLib.*` | 查询、遍历和操作无障碍节点 |

`io`、`os.date`、`os.time` 等已经由 Lua 5.4 标准库提供，不再包装一份同名实现。
`systemTime()` 返回毫秒时间戳，`tickCount()` 返回当前脚本运行时长，
`getNetWorkTime()` 通过网络时间服务器取得格式化时间。

兼容层不会复制旧产品专属的悬浮控制栏事件、配置面板或插件生命周期。相同用途请使用小鱼
精灵现有的 `dialog`、`hud`、`web`、`ui` 和 `imgui`；不存在真实实现的接口不会提供空操作
占位。
