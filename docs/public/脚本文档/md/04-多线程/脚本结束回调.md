**方法名称：** 注册脚本结束回调。

**语法：** `setStopCallBack(callback)`

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `callback` | `function` | 是 | 接收 `error, exitCode` 的结束回调；重复注册时以后一次为准。 |

| 回调参数 | 类型 | 说明 |
|---|---|---|
| `error` | `boolean` | 正常执行到主脚本返回为 `false`；主动停止或运行错误为 `true`。 |
| `exitCode` | `integer` | `0` 正常完成，`1` 主动停止，`2` Lua 运行错误。 |

| 返回值 | 说明 |
|---|---|
| 无 | 注册成功时不返回值；参数不是函数时抛出参数错误。 |

**详细说明：**

主脚本结束后，引擎先停止并回收所有 Lua 子线程，再在当前 `LuaRuntime` 销毁前调用回调。
回调适合释放脚本资源和记录状态，不应启动长期任务或显示需要继续等待的界面。回调自身报错
只写入引擎日志，不会覆盖主脚本原来的结束结果。

**使用示例：**

```lua
setStopCallBack(function(hasError, exitCode)
    print("脚本结束", hasError, exitCode)
end)
```
