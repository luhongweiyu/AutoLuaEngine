```lua
local shared = { count = 0, running = true }

local thread = m.thread.newThread(function(step)
    while shared.running do
        shared.count = shared.count + step
        sleep(20)
    end
end, 2)

sleep(200)
shared.running = false
thread:stopThread()
print(shared.count)
```

## 脚本模型

子任务与主任务共享 `_G`、全局 table、`package.loaded` 和已导入 Java 类。多个任务可以
分别等待 `sleep`、界面事件或 Java 调用，但 Lua 代码和 Lua 回调会依次执行，不应把共享
table 的一次复合读写假设为真正并行。

`tickCount()` 在所有子任务中使用同一个顶层脚本开始时间。

## 脚本 API

小鱼精灵 API：

```lua
m.thread.beginThread(callback, ...)
local thread = m.thread.newThread(callback, ...)
thread:stopThread()
```

懒人精灵兼容 API：

```lua
m.useApi("lr")

beginThread(callback, ...)
local thread = Thread.newThread(callback, ...)
thread:stopThread()
```

## 运行规则

- `callback` 必须是 Lua function，后续参数原样传给回调。
- `beginThread` 不返回线程对象；`newThread` 返回可调用 `stopThread` 的对象。
- 同时运行的用户子线程最多 10 个；超过限制直接产生 Lua 错误。
- 子线程错误只结束该子线程并写入引擎错误日志，不直接结束主脚本。
- `sleep`、界面事件等待和 Java 调用期间，其他可运行的脚本子任务可以继续执行。
- ImGui 等引擎内部任务不占用上述 10 个用户子线程名额。

## 停止和回收

`thread:stopThread()` 请求指定子线程停止，并等待它完成退出。目标任务在继续执行 Lua、
结束 `sleep` 或界面等待时响应停止。

主脚本正常结束、发生错误或收到 App 停止请求时，引擎会停止并等待全部子线程退出。自然
结束的线程也会自动回收，不需要再调用额外的释放函数。

需要在这一时刻释放脚本级资源时，可使用 `setStopCallBack(callback)`。结束回调在全部
子线程回收后执行，结束码为 `0` 正常、`1` 主动停止、`2` 运行错误；详见“脚本结束回调”。
