**方法名称：** `m.ime` 输入控制补充方法。

**语法：** `m.ime.deleteChar()`、`m.ime.finishInput()`、`m.ime.keyEvent(action, keyCode)`。

**参数说明：**

| 方法 | 参数 | 返回值 |
|---|---|---|
| `m.ime.deleteChar()` | 无 | `boolean` |
| `m.ime.finishInput()` | 无 | `boolean` |
| `m.ime.keyEvent(action, keyCode)` | Android 按键 action 和 keyCode | `boolean` |

| 返回值 | 说明 |
|---|---|
| `true` | 命令已交给当前活动的小鱼精灵输入法。 |
| `false` | 输入法当前不能提交该操作。 |

**详细说明：**

这些方法属于正式的 `m.ime` 模块，和本章已有的 `lock`、`setText`、`unlock` 使用同一套小鱼
精灵输入法。默认全局 `ime` 指向同一张表。

调用前应先按本章概述完成 `m.ime.lock()`，并确保目标输入框已经获得焦点。平台调用错误会抛出
Lua 错误，不会伪装成成功。

```lua
assert(m.ime.lock())
assert(m.ime.setText("小鱼精灵"))
assert(m.ime.deleteChar())
assert(m.ime.keyEvent(0, 66)) -- ACTION_DOWN + Enter
assert(m.ime.keyEvent(1, 66)) -- ACTION_UP + Enter
assert(m.ime.finishInput())
assert(m.ime.unlock())
```
