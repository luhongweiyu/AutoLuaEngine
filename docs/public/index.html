One core · Three languages

Lightweight scripting

Lua · 轻量而完整

语法紧凑、嵌入成本低，适合快速编排设备、图像、输入和脚本界面能力。

local x, y = m.findColors(
  0, 0, 1079, 1919,
  1, 0x101010, "0|0|F05B35"
)

if x then
  m.touchDown(0, x, y)
  m.touchUp(0)
end
Event-driven ecosystem

JavaScript · 生态与事件循环

熟悉的异步表达与丰富生态，让设备自动化能够自然连接 Web 和工具工作流。

const [x, y] = m.findColors(
  0, 0, 1079, 1919,
  1, 0x101010, "0|0|F05B35"
);

if (x != null) {
  m.touchDown(0, x, y);
  m.touchUp(0);
}
Concurrent engineering

Go · 并发与工程化

用清晰的工程结构和并发模型组织复杂任务，让自动化项目更易扩展和维护。

point, err := xiaoyv.FindColors(ctx, query)
if err == nil && point != nil {
  _ = xiaoyv.Tap(ctx, point.X, point.Y)
}
